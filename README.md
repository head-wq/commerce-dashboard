# 커머스팀 현황 대시보드

2026년 8월 커머스팀 실적을 정리한 정적 대시보드입니다. 원본 `커머스팀_현황_2026_08.pdf`의 수치를 옮겨 담았습니다.

## 구성

빌드 도구·의존성 없는 단일 HTML 파일입니다.

```
index.html   # 대시보드 전체 (스타일·데이터·렌더링 포함)
```

## 로컬에서 보기

`index.html`을 브라우저로 열면 됩니다. 또는:

```bash
npx serve .
```

## 데이터 수정

`index.html` 하단 `<script>` 안의 `BRANDS` 배열만 고치면 됩니다. 브랜드 하나가 객체 하나이고, 항목을 추가하면 카드가 자동으로 늘어납니다.

```js
{
  name: "브랜드명",
  goalText: "목표 1억", rate: 77, hit: false,   // hit: 목표 달성 여부 (카드 색상 결정)
  roas: "545%",
  revenue: "7,672만", revenueNote: "목표 대비 −2,328만", revenueDir: "dn",  // "up" | "dn"
  weekGoal: 2258,                                // 주 목표 (점선 위치)
  weeks: [{ label: "1주", v: 2023 }, ...],       // 주별 매출 (만원)
  ...
}
```

주 목표를 넘긴 주는 브랜드 색으로, 못 넘긴 주는 회색으로 자동 표시됩니다.

Vercel에 정적 사이트로 배포합니다. 빌드 설정 없이 저장소를 연결하면 그대로 서빙됩니다.
