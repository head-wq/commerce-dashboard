# 팀별 현황판

아카데미 · 대행 마케팅파트 · 대행팀 유튜브파트 · 커머스 — 팀별로 한 페이지씩 구성한 정적 대시보드입니다.

## 구성

빌드 도구도 의존성도 없습니다. HTML 파일을 열면 그대로 동작합니다.

```
index.html               # 전체 개요 + 팀 이동
academy.html             # [1] 아카데미
agency-marketing.html    # [2] 대행 마케팅파트
agency-youtube.html      # [3] 대행팀 유튜브파트
commerce.html            # [4] 커머스
assets/
  data.js                # ★ 모든 팀의 숫자 (여기만 고치면 됩니다)
  ui.js                  # 그래프·표·카드 그리는 코드
  style.css              # 디자인
```

## 수치 고치는 법

`assets/data.js` **한 파일**만 열면 됩니다. 팀별로 구역이 나뉘어 있고, 숫자를 바꾸면 표·그래프·비율·합계가 전부 자동으로 다시 계산됩니다.

```js
agencyMarketing: {
  revenue: { v: "1.42억", note: "인당 2,029만" },
  clients: { v: "23개사", note: "전월 21개사" },
  ...
}
```

### "샘플" 표시 없애기

아직 실제 값을 못 받은 항목에는 화면에 주황색 `샘플` 딱지가 붙습니다. 실제 숫자로 채운 뒤 해당 항목의 `sample: true` 를 `false` 로 바꾸면 딱지가 사라집니다. 페이지 전체가 샘플인 팀은 각 페이지 상단 배너 문구도 함께 지워주세요.

## 그래프 종류

`assets/ui.js` 에 들어 있습니다. 라이브러리 없이 순수 SVG/CSS로 그립니다.

| 함수 | 용도 |
|---|---|
| `kpi` / `kpis` | 숫자 카드 |
| `bars` | 세로 막대 (`goal` 로 목표 점선, `dim:true` 면 미달 막대를 회색 처리) |
| `line` | 꺾은선 — 일별 추이용 |
| `hbars` | 가로 막대 — 채널별 비교용 |
| `donut` | 도넛 + 범례 — 비중용 |
| `table` | 표 (합계 행 지원) |
| `progress` | 진행률 막대 |
| `notes` | 잘된 점 / 시도할 것 목록 |

## 로컬에서 보기

`file://` 로 열면 브라우저 보안 정책 때문에 `assets/` 스크립트가 막힐 수 있습니다. 간단한 서버로 여세요.

```bash
npx serve .
```
